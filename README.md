# DevAtlas

**Navigate the world of GitHub.** Discover developers, explore their
repositories, save favorites, and see repository insights.

> Status: in development (Stage 0: foundation)

## Tech stack

React · Vite · TypeScript · React Compiler · Tailwind CSS · shadcn/ui ·
React Router · TanStack Query · Zod · nuqs

## Getting started

    npm install
    npm run dev

Optional: copy `.env.example` to `.env.local` and add a read-only GitHub
token to raise API rate limits in development.

DevAtlas is an independent project and is not affiliated with or
endorsed by GitHub.
